PDFix – Markenpaket
====================

app-icon/
  pdfix-app-icon.svg        App-Icon (Open Book, rot), Master ab 32 px
  pdfix-app-icon-small.svg  Vereinfachte Fassung für 16/24 px
  pdfix.ico                 Windows (16–256 px, kleine Größen nutzen die vereinfachte Fassung)
  pdfix.icns                macOS (16–1024 px)
  png/                      16, 24, 32, 48, 64, 128, 256, 512, 1024 px

document-icon/
  pdfix-document.svg        Dokument-Icon (Doc · Clean), Master ab 32 px
  pdfix-document-small.svg  Vereinfachte Fassung für 16/24 px (Blatt + rote Ecke)
  pdfix-document.ico        Windows-Dateityp-Icon (16–256 px)
  png/                      16–512 px

wordmark/
  pdfix-wordmark(.svg/-white.svg)          horizontal; -white für dunkle Hintergründe
  pdfix-wordmark-stacked(.svg/-white.svg)  gestapelt
  png/                                     4-fache Auflösung, transparent
  Schrift: Manrope (SIL Open Font License, siehe Manrope-OFL.txt), in Pfade umgewandelt –
  keine Schriftinstallation nötig.

Farben
  Rot (Akzent)   #e0412f
  Rot hell       #ee5a46   (Verlauf oben)
  Rot dunkel     #a92a1c   (Verlauf unten)
  Tinte          #16181d
